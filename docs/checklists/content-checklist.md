# Content Checklist

## Structure

- [ ] Site metadata (title, description, keywords, URL, OG image)
- [ ] Navigation links (4-8 items, with href targets)
- [ ] Hero headline + subtitle + CTA
- [ ] About section (intro paragraphs, values)
- [ ] History / timeline (events with years)
- [ ] Products / services (categories with items)
- [ ] Accommodations / rooms (detailed per unit)
- [ ] Gallery (10-30 images with captions)
- [ ] Location (address, map, distances)
- [ ] Contact (phone, email, form labels, hours)
- [ ] Footer (copyright, social links, footer links)

## Quality

- [ ] No placeholder text (Lorem ipsum, etc.)
- [ ] All phone numbers include country code
- [ ] All email addresses valid
- [ ] All URLs start with https://
- [ ] Grammar checked (native speaker or AI)
- [ ] Spelling checked
- [ ] Consistent terminology (e.g., "cabin" vs "cottage")
- [ ] No duplicate content between languages
- [ ] All facts verified with client

## Bilingual

- [ ] Finnish content complete
- [ ] English content complete
- [ ] Both languages contain the same information density
- [ ] Language switch button text translated
- [ ] No language mixing (FI strings in EN files or vice versa)

## Legal

- [ ] Copyright year correct
- [ ] Privacy policy link (or placeholder)
- [ ] Terms of service link (or placeholder)
- [ ] Cookie notice (if required by law)
- [ ] GDPR compliance check (EU businesses only)
