# Research Checklist

Before building a farm / local business website, complete the following research.

## Business

- [ ] Business name (legal / trade)
- [ ] Business type (farm, restaurant, hotel, retail, service)
- [ ] Year founded / family history
- [ ] Owner / operator names
- [ ] Core values (3-5 items)
- [ ] Business narrative — origin story, what makes them unique

## Products / Services

- [ ] Product categories (meat, dairy, vegetables, etc.)
- [ ] Individual items per category with descriptions
- [ ] Pricing (optional — note if sold in physical shop)
- [ ] Seasonal availability
- [ ] Production methods (organic, grass-fed, etc.)

## Accommodations (if applicable)

- [ ] Number of units (cabins, rooms, apartments)
- [ ] Per-unit: name, capacity, size, layout, amenities
- [ ] Pricing and seasonal rates
- [ ] Booking URL or phone number
- [ ] Common rules (pets, smoking, cleaning, etc.)
- [ ] Contact person for bookings

## Location

- [ ] Full address (street, postal code, city, country)
- [ ] GPS coordinates
- [ ] Google Maps Embed URL / iframe code
- [ ] Distances from nearest cities / airports

## Contact

- [ ] Phone numbers (with country codes)
- [ ] Email addresses
- [ ] Contact persons per department
- [ ] Opening hours / season
- [ ] Preferred contact method

## Social Media

- [ ] Facebook page URL
- [ ] Instagram handle
- [ ] Other platforms (Twitter, TikTok, LinkedIn, YouTube)
- [ ] Any existing online reviews or listings

## SEO

- [ ] Target keywords (primary + secondary)
- [ ] Competitor URLs (5-10 similar businesses)
- [ ] Existing rankings (if any)
- [ ] Target audience demographics

## Images

- [ ] Exterior photos (facade, surroundings, landscape)
- [ ] Interior photos (shop, production, rooms)
- [ ] Product photos (each category)
- [ ] People photos (owners, staff, customers)
- [ ] Aerial / drone photos
- [ ] Historic photos (for timeline)
- [ ] Logo (vector if possible)
