# Image Checklist

## Capture

- [ ] Exterior / building shots (front, sides, surroundings, landscape)
- [ ] Interior shots (shop, common areas, production spaces)
- [ ] Product shots (each category, multiple angles if needed)
- [ ] People shots (owners, staff, customers at work)
- [ ] Accommodation shots (each room/unit, multiple angles)
- [ ] Detail shots (amenities, special features, craftsmanship)
- [ ] Aerial / drone shot (optional — great for farms and hotels)
- [ ] Historic photos (optional — for timeline)
- [ ] Logo / brand mark (vector format preferred)

## Specifications

- [ ] Minimum 1200px wide (for hero/full-width images)
- [ ] Minimum 800px wide (for card/grid images)
- [ ] Aspect ratios consistent within categories
- [ ] No compression artifacts or visible quality loss
- [ ] Correct white balance and exposure
- [ ] Landscape orientation for hero images
- [ ] Mix of landscape and portrait for galleries

## Processing

- [ ] Converted to WebP format
- [ ] Quality 80-85 (balance size vs quality)
- [ ] Placeholder images created (40px wide, WebP)
- [ ] Responsive variants created (480px, 768px for hero images)
- [ ] File names: lowercase, hyphens, descriptive (e.g., farm-aerial.webp)
- [ ] Image directory clean (no source RAW/TIFF files in public/)
- [ ] Total image size optimized (target: <200 KB per large image)

## Metadata

- [ ] Alt text for every image (Finnish)
- [ ] Alt text for every image (English)
- [ ] Captions for gallery images (optional but recommended)
- [ ] Open Graph image (1200x630px, WebP)
- [ ] Favicon (SVG preferred)

## Verification

- [ ] All image paths exist and are correct
- [ ] No broken images in development build
- [ ] No broken images in production build
- [ ] Placeholder images load before full images
- [ ] Hero image loads with priority fetchPriority
- [ ] Gallery images lazy-loaded
