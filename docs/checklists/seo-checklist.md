# SEO Checklist

## On-Page

- [ ] Title tag set (50-60 characters, primary keyword first)
- [ ] Meta description set (150-160 characters)
- [ ] Meta keywords set (optional — modern SEO ignores these)
- [ ] Canonical URL set
- [ ] hreflang tags (each language + x-default)
- [ ] robots.txt present and configured
- [ ] sitemap.xml present with correct URLs
- [ ] Open Graph tags (title, description, image, locale, type, URL, site_name)
- [ ] Twitter Card tags (card type, title, description, image)
- [ ] Favicon (SVG preferred)
- [ ] Apple touch icon
- [ ] Web manifest (site.webmanifest)

## Structured Data (JSON-LD)

- [ ] LocalBusiness / Organization schema (name, address, phone, geo, URL)
- [ ] Accommodation schema if applicable (LodgingBusiness)
- [ ] BreadcrumbList schema
- [ ] Organization schema (logo, social profiles)
- [ ] All Schema.org fields validate at validator.schema.org
- [ ] Address as PostalAddress (street, postalCode, locality, country)
- [ ] GeoCoordinates present
- [ ] SameAs (social media profiles) present
- [ ] Telephone with country code

## Content

- [ ] Each page/section has a unique `<h1>` (hero title)
- [ ] Heading hierarchy is logical (h1 → h2 → h3)
- [ ] All images have alt text
- [ ] Internal links use descriptive anchor text
- [ ] External links open in new tab with rel="noopener noreferrer"
- [ ] No duplicate meta tags between languages

## Technical

- [ ] `lang` attribute on `<html>` element
- [ ] Page loads over HTTPS
- [ ] No broken links
- [ ] No 404 pages in navigation
- [ ] Sitemap submitted to Google Search Console
- [ ] Sitemap submitted to Bing Webmaster Tools
- [ ] robots.txt referenced in sitemap
- [ ] Fast page load (Lighthouse SEO score ≥ 90)

## Local SEO (for physical businesses)

- [ ] Google Business Profile created/claimed
- [ ] NAP (Name, Address, Phone) consistent across web
- [ ] Address on contact page
- [ ] Google Maps embed on location page
- [ ] Distances from major cities listed
- [ ] Opening hours on page
